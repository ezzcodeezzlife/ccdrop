ccdrop

Share Anthropic Claude Code chat sessions between computers with a 4-digit PIN. RAM-only relay, auto-deleted on download, no accounts, no logs.

Install on npm View source on GitHub Public relay

Quick start

On the computer with the chat:

npx ccdrop

Then on the other computer:

npx ccdrop 4829

Why ccdrop?

  • One command, no setup, no accounts.
  • 4-digit PIN transfer — way faster than copy-paste.
  • Cross-platform: macOS, Linux, Windows.
  • Privacy-by-default: RAM-only relay, auto-deleted on download.
  • 15-minute expiry — even unused PINs self-destruct.
  • Self-hostable relay on Vercel / any Node 18+ host.
  • MIT licensed open source.

Commands

  • npx ccdrop — share a chat session, get a 4-digit PIN.
  • npx ccdrop <PIN> — import a chat session using the PIN.
  • npx ccdrop server — run a local relay on http://localhost:3000.
  • npx ccdrop -s <url> — point at a custom relay.

Privacy

The relay is RAM-only. Sessions live in an in-memory Map, are wiped the instant they are downloaded, expire after 15 minutes, and are otherwise never logged. There are no accounts and no telemetry.

Self-hosting

npx ccdrop server
# or
npm run deploy   # deploys api/index.js to Vercel

Then point clients at your URL:

npx ccdrop -s https://your-app.vercel.app
